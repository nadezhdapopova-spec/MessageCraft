# Проект "MessageCraft"

## Описание:
**MessageCraft** — это веб-приложение на **Django**, предназначенное для управления email-рассылками, администрирования клиентов и получения статистики.

Проект реализует систему прогревающих рассылок, которые помогают удерживать клиентов и повышать их вовлечённость.

Приложение создано в учебных целях и полностью соответствует техническому заданию: включает управление пользователями, рассылками, клиентами, отчётность, логирование и автоматическую отправку сообщений по расписанию.

## 🚀 Основной функционал

### 1. Управление клиентами
- Добавление, редактирование, просмотр и удаление клиентов (получателей рассылок).
- Поля модели:
  - **Email** — уникальный адрес клиента.
  - **Ф. И. О.**
  - **Комментарий**

### 2. Управление сообщениями
- Создание и редактирование шаблонов писем.
- Поля модели:
  - **Тема письма**
  - **Тело письма**

### 3. Управление рассылками
- Создание, редактирование и удаление рассылок.
- Статусы рассылки:
  - 🟡 *Создана* — еще не была отправлена.
  - 🟢 *Запущена* — активна, отправлена хотя бы один раз.
  - 🔴 *Завершена* — время рассылки истекло.
- Каждая рассылка связывается с сообщением и одним или несколькими получателями.

### 4. Отправка сообщений
- Поддерживается **ручная отправка** через интерфейс.
- Возможна **отправка из командной строки**.

### 5. Попытки рассылок
- Фиксируются все попытки с деталями:
  - Дата и время отправки.
  - Статус: «успешно» / «неуспешно».
  - Ответ почтового сервера.

### 6. Главная страница
- Отображает общую статистику:
  - Количество всех рассылок.
  - Количество активных рассылок.
  - Количество уникальных получателей.

## ⚙️ Расширенные возможности

### 7. Регистрация и аутентификация
- Регистрация с подтверждением email.
- Авторизация, выход из системы, восстановление пароля.
- Разграничение доступа по ролям.

### 8. Статистика и отчёты
- Подробная статистика по:
  - Количеству успешных и неуспешных отправок.
  - Количеству доставленных сообщений.
- Просмотр статистики доступен пользователю только по своим рассылкам.

### 9. Система ролей и прав доступа
- **Пользователь:**
  - Полное управление своими клиентами и рассылками.
  - Просмотр своей статистики.
- **Менеджер:**
  - Просмотр всех рассылок и клиентов.
  - Просмотр и блокировка пользователей.
  - Отключение чужих рассылок.

### 10. Кеширование
- Серверное и клиентское кеширование данных клиентов и рассылок для повышения производительности.

### ⭐ Дополнительно
- **Автоматическая отправка сообщений по расписанию** реализована с помощью `django-apscheduler`.
- **Логирование** всех ключевых событий, включая операции с пользователями, рассылками и ошибками, с раздельными лог-файлами:
  - `django.log`
  - `clients.log`
  - `campaigns.log`
  - `mailings.log`

## ⚙️ Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/nadezhdapopova-spec/MessageCraft.git
   cd MessageCraft
   ```
2. Установите зависимости:
   ```
   poetry install
   ```
3. Активируйте виртуальное окружение:
   ```
   poetry shell
   ```
4. Выполните миграции, создайте суперпользователя, менеджера, заполните базу данных тестовыми данными:
python manage.py migrate
python manage.py create_custom_superuser
python manage.py create_custom_manager
python manage.py generate_test_data

5. Запустите сервер:
python manage.py runserver

6. Откройте в браузере:
http://127.0.0.1:8000/


## 📊 Использование

Панель администратора: /admin/

Основные разделы:

/clients/ — управление клиентами.

/mailings/ — управление рассылками.

/campaigns/ — шаблоны и попытки отправок.

/reports/ — статистика и аналитика.

Автоматическая отправка сообщений выполняется планировщиком django-apscheduler.

## 🧱 Архитектура проекта

Приложение разделено на модули:

clients — управление получателями.

mailings — рассылки и сообщения.

campaigns — автоматизация и попытки отправки.

reports — отчётность и статистика.

users — аутентификация и права доступа.
