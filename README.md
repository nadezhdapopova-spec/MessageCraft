# Проект "MessageCraft"

## Описание:
**MessageCraft** — это веб-приложение на **Django**, предназначенное для управления email-рассылками, 
клиентами, пользователями и статистикой.

Проект реализует систему прогревающих рассылок, помогает удерживать клиентов и повышать их вовлечённость.
Создан в учебных целях и включает все элементы профессиональной CRM-системы:
управление пользователями, ролями, рассылками, клиентами, отчётность, логирование 
и автоматическую отправку писем по расписанию.

## 🚀 Основной функционал

### 1. Управление клиентами
- Добавление, редактирование, просмотр и удаление клиентов (получателей рассылок).
- Поля модели:
  - **Email** — уникальный адрес клиента.
  - **Ф. И. О.**
  - **Комментарий**

### 2. Управление сообщениями
- Создание и редактирование шаблонов писем.
- Поля модели:
  - **Тема письма**
  - **Тело письма**
  - **HTML-формат**: выбирается «Да / Нет»

### 3. Управление рассылками
- Создание, редактирование и удаление рассылок.
- Статусы рассылки:
  - 🟡 *Создана* — еще не была отправлена.
  - 🟢 *Запущена* — активна, отправлена хотя бы один раз.
  - 🔴 *Завершена* — время рассылки истекло.
- Каждая рассылка связывается с сообщением и одним или несколькими получателями.

### 4. Отправка сообщений
- Поддерживается **ручная отправка** через интерфейс.
- Возможна **отправка из командной строки**.

### 5. Попытки рассылок
- Фиксируются все попытки отправки с деталями:
  - Дата и время отправки.
  - Статус: «успешно» / «неуспешно».
  - Ответ почтового сервера.

### 6. Главная страница
- Отображает общую статистику:
  - Количество всех рассылок.
  - Количество активных рассылок.
  - Количество уникальных получателей.

## ⚙️ Расширенные возможности

### 7. Регистрация и аутентификация
- Регистрация с подтверждением email.
- Авторизация, выход из системы, восстановление пароля.
- Разграничение доступа по ролям.

### 8. Отчётность и аналитика
- Подробные отчёты по отправленным письмам и кампаниям.
- Статистика успешных и неуспешных отправок.
- Просмотр доступен только владельцу рассылок или менеджеру.

### 9. Система ролей и прав доступа
- **Пользователь:**
  - Управляет своими клиентами и рассылками. 
  - Просматривает собственную статистику.
- **Менеджер:**
  - Имеет доступ к панели управления (management_panel). 
  - Просматривает все рассылки и пользователей. 
  - Может блокировать пользователей и останавливать рассылки.
- **Суперпользователь:**
- Имеет полный доступ ко всем разделам и данным.

### 10. Панель менеджера(management_panel)
- Отдельное приложение для менеджеров.
- Основные функции:
  - Просмотр всех зарегистрированных пользователей.
  - Просмотр всех активных и остановленных рассылок.
  - Массовая блокировка пользователей.
  - Массовая остановка кампаний.
- Доступ возможен только для пользователей, принадлежащих к группе manager.
- Все действия логируются и сопровождаются всплывающими сообщениями (Bootstrap alerts).

### 11. Кеширование
- Серверное и клиентское кеширование данных клиентов и рассылок для повышения производительности.

### ⭐ Дополнительно
- **Автоматическая отправка сообщений по расписанию** реализована с помощью `django-apscheduler`.
- **Логирование** всех ключевых событий, включая операции с пользователями, рассылками и ошибками.

- **Python 3.12**
- **Django 5**
- **django-apscheduler**

## ⚙️ Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/nadezhdapopova-spec/MessageCraft.git
   cd MessageCraft
   ```
2. Установите зависимости:
   ```
   poetry install
   ```
3. Активируйте виртуальное окружение:
   ```
   poetry shell
   ```
4. Выполните миграции, создайте суперпользователя, менеджера, 
заполните базу данных тестовыми данными:
python manage.py migrate
python manage.py create_custom_superuser
python manage.py create_custom_manager
python manage.py generate_test_data
python manage.py add_contacts

5. Запустите сервер:
python manage.py runserver

6. Откройте в браузере:
http://127.0.0.1:8000/


## 📊 Использование

Панель администратора: /admin/

Основные разделы:

/clients/ — управление клиентами.

/mailings/ — управление рассылками.

/campaigns/ — шаблоны и попытки отправок.

/reports/ — статистика и аналитика.

/management_panel/ - панель менеджера (пользователи и рассылки)

Автоматическая отправка сообщений выполняется планировщиком django-apscheduler.

## 🧱 Архитектура проекта

Приложение разделено на модули:

clients — управление получателями.

mailings — рассылки и сообщения.

campaigns — автоматизация и попытки отправки.

reports — отчётность и статистика.

management_panel — интерфейс для менеджеров (блокировка пользователей, остановка рассылок).

users — аутентификация и права доступа.
