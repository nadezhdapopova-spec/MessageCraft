# 📧 MessageCraft

**MessageCraft** — backend-ориентированное веб-приложение для управления email-кампаниями, клиентской базой и аналитикой рассылок.

Проект реализует полноценный сервис управления прогревающими и маркетинговыми рассылками с ролевой моделью доступа, 
автоматическим планированием отправок, отчётностью и логированием бизнес-операций.

## Ключевые возможности

### Email-кампании

- Создание и управление рассылками

- Привязка к шаблону сообщения и группе получателей

- Поддержка HTML и plain-text писем

- Ручной запуск из интерфейса

- Запуск через CLI

- Автоматическая отправка по расписанию

### Отслеживание попыток отправки

- Логирование каждой попытки

- Статус: успешно / ошибка

- Ответ SMTP-сервера

- Хранение истории отправок

### Аналитика и отчётность

- Общее количество кампаний

- Активные рассылки

- Количество уникальных клиентов

- Статистика успешности отправок

- Подсчёт процента доставки

- Фильтрация по статусам

- Экспорт отчётов в CSV (UTF-8 с BOM для совместимости с Excel)

## Архитектура

#### Проект разделён на независимые модули:

**users** — кастомная модель пользователя, роли и аутентификация

**clients** — управление получателями

**mailings** — рассылки и шаблоны сообщений

**campaigns** — попытки отправки и автоматизация

**reports** — аналитика и агрегированные данные

**management_panel** — панель управления для менеджеров

### Архитектурные принципы

- Разделение ответственности между приложениями

- Object-level permission checks

- Role-based QuerySet filtering

- Мягкое управление статусами вместо физического удаления

- Централизованное логирование бизнес-событий

- Кэширование пользовательских списков

- Планировщик задач для автоматизации отправок

### Система ролей

**Пользователь**

- Управляет только своими клиентами и рассылками

- Просматривает собственную статистику

**Менеджер**

- Доступ к панели управления

- Просмотр всех пользователей и кампаний

- Массовая блокировка пользователей

- Принудительная остановка рассылок

**Суперпользователь**

- Полный доступ ко всем данным и разделам

**Контроль доступа реализован через:**

- Django permissions

- Проверки в CBV

- Object-level ограничения

- Фильтрацию QuerySet по владельцу

### Планирование рассылок

- Автоматическая отправка реализована через django-apscheduler:

    - Кампания активируется по времени
    
    - Возможность ручной остановки
    
    - Повторные попытки отправки
    
    - Смена статуса в зависимости от состояния
      - 🟡 *Создана* — еще не была отправлена.
      - 🟢 *Запущена* — активна, отправлена хотя бы один раз.
      - 🔴 *Завершена* — время рассылки истекло.
      - 🔴 *Отключена* — принудительно остановлена менеджером.

## Производительность

### Кэширование

- Кэширование списков клиентов и кампаний

- Инвалидация при изменении данных

- Использование Django Cache Framework / Redis

### Логирование

- Используется RotatingFileHandler для:

    - регистрации пользователей
    
    - запуска и остановки кампаний
    
    - попыток отправки
    
    - ошибок SMTP
    
    - действий менеджеров

- Логи позволяют отслеживать ключевые бизнес-процессы.

## Установка

   ```bash
   git clone https://github.com/simbarilion/MessageCraft.git
   cd MessageCraft
   poetry install
   poetry shell
   ```
Миграции и подготовка данных:
   ```
   python manage.py migrate
   python manage.py create_custom_superuser
   python manage.py create_custom_manager
   python manage.py generate_test_data
   python manage.py add_contacts
   ```

Запуск:

```
python manage.py runserver
```

Открыть в браузере:

```
http://127.0.0.1:8000/
```
